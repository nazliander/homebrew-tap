# nazliander's Homebrew tap

Command-line tools by [@nazliander](https://github.com/nazliander), installable with Homebrew.

```sh
brew tap nazliander/tap
brew install <formula>
```

| Formula | What it does |
|---|---|
| [hooktop](https://github.com/nazliander/hooktop) | See what Claude Code is really doing: tool calls, subagents, CPU/RAM and token costs, live in your terminal. |

Formulae in `Formula/` are updated automatically when a tool is released.
